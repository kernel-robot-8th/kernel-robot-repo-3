선반 영상 영역 입력 도구

저장된 관측 PNG에서 각 선반 칸의 경계를 클릭해 polygon 초안을 만듭니다. 좌표는 표시 크기가 아니라 원본 PNG 픽셀 기준입니다. 다운로드에는 원본 PNG SHA-256과 해상도를 함께 넣어 CLI가 task 관측 프레임과 대조합니다. PNG는 최대 64 MiB, 영역은 최대 64개, 영역당 512개 점, JSON은 최대 1 MB입니다. 물리 측정이나 로봇 제어 허가를 대신하지 않습니다.

먼저 작업 이력의 프레임 링크에서 저장된 PNG를 내려받아 선택하세요.

이미지가 선택되면 클릭으로 꼭짓점을 추가할 수 있습니다.

완료한 영역

    최소 3개 점을 찍고 polygon을 완료하세요. 서로 겹치는 영역은 허용되지만 관측 비교 시 겹친 후보는 모호로 표시됩니다. JSON을 만든 뒤 저장된 task 응답과 함께 scripts/calibrate_shelf_regions.py에 전달하세요.
