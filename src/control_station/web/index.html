학습 정책으로 집기

        
정책 목록 확인 중

      

      
버튼을 누르면 그 물체만 집도록 학습한 LeRobot ACT 정책을 OMX 워커가 실행해 Pinky 위에 올립니다. 먼저 정면 캠에서 그 물체가 한 칸에 보이는지 확인하고, 못 찾으면 이유를 보여 준 뒤 확인 없이 실행할지 묻습니다. 정책은 위치를 입력으로 받지 않고 자기 카메라로 물체를 찾으므로, 칸은 물체가 있다는 근거로만 기록됩니다. 정책이 쉬는 자세로 돌아오면 멈추고 home으로 맞춥니다. 적재 성공은 확인하지 않으므로 결과는 확인 불가로 남고, 현장을 보고 현장 확인 완료로 닫습니다.

      

        
        
        
        
      

      
보고 집기는 학습 정책 없이, 정면 캠이 잰 물체 중심을 팔 좌표로 바꿔 그리퍼 열기 → 물체 위 → 내려가기 → 닫기 → 들기 → Pinky 위 놓을 자세(place_pinky) → 놓기 → home 순서로 움직입니다. 워커를 --pick-stop-after lift로 켜면 들어 올린 채 멈춥니다. 잡혔는지·놓였는지는 확인하지 않으므로 결과는 확인 불가로 남습니다. 물체 위로 이동은 정면 캠이 잰 물체 위치를 현장에서 맞춘 카메라→팔 변환(CONTROL_STATION_CAMERA_TO_ARM)으로 팔 좌표로 바꿔, 손가락 끝이 물체 6 cm 위·2 cm 앞에 오도록 손목을 45° 아래로 하고 이동합니다. 변환 오차는 약 1 cm이며 경로의 충돌은 검사하지 않습니다. 정면 캠 검출에서 이 물건이 정확히 한 칸 안에만 보일 때 그 칸으로 이동 명령을 만듭니다. 영상이 오래됐거나, 여러 칸에 있거나, 칸 경계에 걸리면 명령을 만들지 않고 이유를 보여 줍니다. 아래는 칸을 직접 고르는 수동 명령입니다.

      

        
        
        
        
        
        
        
        
        
        
        
      

      
원상복귀는 워커가 기록해 둔 home 자세로 팔을 돌려보냅니다. 좌표로 이동은 omx_link0(팔 받침 바닥, 어깨 회전축 1.1 cm 뒤 원점, 앞 +X, 팔 기준 왼쪽 +Y, 위 +Z) 기준 그리퍼 턱 부착점 위치이며 손목은 수평입니다. 워커가 가져가서 ACCEPTED를 보내야 실행됩니다. 연결된 워커가 실물 OMX면 팔이 움직이고, 모의 워커는 움직이지 않습니다. 좌표 확인은 워커가 하며, 관제는 단위 실수(±1 m 초과)만 막습니다.

불러오는 중

      

        
        
      

      
제한된 한국어 문형과 일부 영어 물체/색상어로 작업 폼 초안을 채웁니다. 사람이 검토하고 작업 등록을 눌러야 저장됩니다.

      

        
        
        
        
        
          
          
        
        
        
      

      
대상 필드는 선택 입력입니다. 하나라도 입력하면 대상 종류가 필요합니다. 자연어 해석 값은 초안이므로 검토·수정 후 등록하세요. 색상 힌트 비교는 빨강·파랑·초록·노랑·검정·흰색만 지원하며 미보정 검토용입니다. 다른 색상은 작업 조건에 저장되지만 색상 비교는 지원되지 않는 상태로 표시됩니다.

      

      

        
작업을 불러오는 중…

        
작업을 선택하면 단계와 생성 이력을 볼 수 있습니다.

      

      
작업 등록은 기본 정보와 선택한 대상 조건을 이력에 저장할 뿐, 인식이나 로봇 명령을 실행하지 않습니다.

GET

GET
/api/cameras/{camera_id}/target-observation?class_name=...&color=...&shelf_level=... 대상 관측 및 선택적 색상/층 영역 힌트 비교 (관측 전용)

        
GET
/streams/{camera_id}.mjpg 카메라 영상

        
GET
/api/arm/status 팔 프로세스 상태

        
POST
/api/arm/start 텔레오퍼레이션 시작

        
POST
/api/arm/stop 종료 요청

        
POST
/api/arm/policy/start?profile_id=apple_pick 선택한 학습 정책 1회 실행

        
POST
/api/arm/policy/stop 학습 정책 중단 요청

        
POST
/api/arm/coordinate-target-drafts 미실행 좌표 초안 파일 저장

        
POST
/api/arm/commands OMX 명령 1건을 큐에 등록 (팔당 미완료 명령 1건)

        
GET
/api/arm/commands, /api/arm/commands/{command_id} 명령 목록·워커 접속 상태 / 명령 상세·이벤트

        
GET
/api/arm/{robot_id}/commands/next?worker_id=...&wait_s=20 워커 long-poll (200 명령 / 204 없음)

        
POST
/api/arm/commands/{command_id}/events 워커 이벤트 보고 (ACCEPTED에 200을 받아야 실행)

        
POST
/api/arm/commands/{command_id}/cancel, .../clear-unknown 취소 요청 / UNKNOWN 현장 확인 기록

        
GET
/api/tasks 작업 목록

        
GET
/api/tasks/{task_id} 작업 상세·단계·이벤트

        
POST
/api/tasks 작업 등록 및 선택적 `pick_request` 조건 저장

        
POST
/api/tasks/parse-command 자연어 작업 명령을 검토용 초안으로 해석 (저장·실행 없음)

        
POST
/api/tasks/{task_id}/target-observation 대기 작업에 현재 카메라 후보 판정을 이벤트로 기록

        
POST
/api/tasks/{task_id}/target-selection 특정 관측 event의 후보에 대한 운영자 review 기록 (작업 실행 없음)

        
POST
/api/tasks/{task_id}/projection-draft 오프라인 2D 선반 평면 좌표 초안을 현재 작업 이력에 검토 전용으로 연결

        
GET
/api/tasks/{task_id}/projection-drafts/{event_id}/artifact 이벤트에 연결된 hash 검증 2D 초안 JSON 열람

        
POST
/api/tasks/{task_id}/start 모의 작업 시작 (mock 모드만)

        
POST
/api/tasks/{task_id}/cancel 모의 작업 취소 (mock 모드만)

      

      
자연어 해석은 제한된 규칙 기반 초안이며 모호하거나 검출 클래스와 맞지 않는 대상은 자동 선택하지 않습니다. 작업 등록은 저장만 하고 관측 기록은 task 이벤트를 추가할 뿐 상태를 전이하지 않습니다. task 시작/취소는 mock 모드에서만 동작합니다. 학습 정책 API는 명시적으로 활성화한 경우 실제 LeRobot 로봇 클라이언트를 실행합니다.
